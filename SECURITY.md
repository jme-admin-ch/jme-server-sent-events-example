# JME OSS Security Policy

All JME open-source repositories follow the security issue reporting process outlined in
[jme-admin-ch/SECURITY.md](https://github.com/jme-admin-ch/jme/blob/main/SECURITY.md).

To report a security issue, use the GitHub Security Advisory
[Report a Vulnerability](https://github.com/jme-admin-ch/jme-server-sent-events-example/security/advisories/new) feature.

The JME maintainers will respond with the next steps for handling your report. Please do not publicly disclose a
vulnerability until the maintainers have had the opportunity to investigate and resolve it.
